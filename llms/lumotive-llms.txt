## The Open Lidar API — what it actually is

Lumotive announced an "Open Lidar API" in January 2022. It is a REAL developer
interface, but it is an EMBEDDED HARDWARE-CONTROL API, not an HTTP service:

- It controls Lidar 2.0 hardware in real time with low latency, defining regions of
  interest in the field of view with user-defined frame rate, resolution and range,
  and provides a common point-cloud data format plus basic control of legacy Lidar 1.0
  hardware.
- It is exercised from C/C++ LCM control libraries with Python bindings, shipped as
  shared libraries with the LCM Evaluation Kit (Windows 10 / Ubuntu Linux 20.04, USB).
- Distribution is gated: "The Lumotive Open Lidar API and its supporting hardware
  platform are available now to selected partners by contacting Lumotive."
- Announcement: https://lumotive.com/press-releases/lumotive-introduces-open-lidar-api-to-accelerate-market-adoption-of-software-defined-solid-state-lidar-2-0-solutions/
